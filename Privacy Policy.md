Privacy Policy for ChatGPT Keyboard Remap

Effective date: 2026-04-13

ChatGPT Keyboard Remap is a lightweight Chrome extension that customizes keyboard shortcuts in the ChatGPT message composer.

Data collected
This extension does not collect personal information, account credentials, payment information, chat history, or browsing history for analytics, advertising, or sale.

Settings stored
The extension stores only the settings required for its functionality, such as:
- whether the extension is enabled
- the selected shortcut for sending a message
- the selected shortcut for inserting a newline

How data is used
These settings are used only to provide the extension’s keyboard remapping functionality on ChatGPT pages.

Data sharing
The extension does not sell, transmit, or share user data with third parties.

Remote code
The extension does not execute remotely hosted code.
